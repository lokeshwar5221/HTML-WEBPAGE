# HTML WEBPAGE

A beginner-friendly HTML practice repository containing a collection of daily web development exercises and webpage examples. This project documents my learning journey through HTML by organizing different concepts and practice activities into separate day-wise folders.

## 📌 About the Project

This repository was created to practice and understand the fundamentals of **HTML (HyperText Markup Language)** and webpage development.

The project is organized into multiple daily exercises, starting from basic HTML concepts and gradually practicing different webpage structures and elements.

## 📂 Project Structure

The repository contains:

* `Day1` – HTML fundamentals and basic webpage structure
* `Day2` – HTML elements and formatting
* `Day3` – Links, images, and other HTML components
* `Day4` – Lists and webpage organization
* `Day5` – Tables and structured content
* `Day6` – Forms and input elements
* `Day7` – Additional HTML practice
* `Day8` – Webpage structure and elements
* `Day9` – HTML practice exercises
* `Day10` – Additional webpage exercises
* `Day11` – HTML concepts and practice
* `Day12` – Webpage development exercises
* `Day13` – HTML practice
* `Day14` – HTML webpage exercises
* `Day15` – Additional HTML concepts
* `Day16` – Webpage practice
* `Day17` – Final practice exercises
* `practice.html` – Additional HTML practice page

## 🛠️ Technologies Used

* **HTML5**
* Web browser
* Any text editor or IDE such as VS Code

## 🚀 How to Run

1. Clone the repository:

```bash
git clone https://github.com/lokeshwar5221/HTML-WEBPAGE.git
```

2. Open the project folder in **Visual Studio Code** or another code editor.

3. Open any of the HTML files in a web browser.

4. Explore the different day-wise exercises and examples.

## 🎯 Learning Objectives

This project helps practice:

* HTML document structure
* Headings and paragraphs
* Links and images
* Lists and tables
* Forms and input elements
* Page organization
* Basic webpage development
* Writing and understanding HTML code

The main purpose of this repository is to maintain a collection of HTML learning exercises and track progress while learning web development.
